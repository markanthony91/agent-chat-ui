# Frontend 0.6.5 — currency and line breaks

The shared Markdown renderer interpreted R$ as an inline math delimiter and
collapsed soft paragraph line breaks. Disable single-dollar math parsing and use
CSS white-space: pre-line on paragraphs. Double-dollar math remains supported.
The change applies to new and historical messages without updating stored content.

Validated with four browser cases: old bold summary and new plain summary, each
at 1440px and 390px. Checks cover exact currency values, absence of KaTeX and
stray asterisks, increasing vertical positions for each installment, and no
horizontal overflow. Tests mock the backend, with no real messages or agreements.
TypeScript, targeted ESLint, production build and git diff --check passed.

Runtime 0.14.5 supplies the requested blocks and places the negotiation total
after the installment schedule. No dependencies, APIs or stored instructions changed.
